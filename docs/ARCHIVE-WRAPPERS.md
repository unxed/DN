# External archive wrappers

This is an implementation reference for the archive-wrapper work. It records candidate command-line tools and their ordinary command forms; DN must pass arguments without a shell, preserve the source archive on failed writes, and report a missing optional tool instead of failing. Commands below are not yet a promise that DN implements every operation. A dash means the format is a single compressed stream or the tool has no generally safe in-place operation.

Install examples are for Debian/Ubuntu (`apt`) and Homebrew (`brew`). Package names can differ on other systems. Check the distribution package and the program's own license before redistributing it; DN does not bundle these tools.

| Format / examples | Candidate program | List | Extract | Add / create | Delete | Test | DN reader today | License / install |
|---|---|---|---|---|---|---|---|---|
| ZIP (`.zip`) | `unzip` + `zip` | `unzip -Z -1 archive.zip` | `unzip -o archive.zip -d DIR` | `zip -r archive.zip PATH...` | `zip -d archive.zip MEMBER...` | `unzip -t archive.zip` | Built-in reader; Unix defaults already use `zip`/`unzip` for operations | Info-ZIP license; `unzip` / `zip`, `brew install unzip zip` |
| 7z (`.7z`) | `7zz`, `7z`, or `7za` | `7z l -slt -ba archive.7z` | `7z x -y -oDIR archive.7z` | `7z a archive.7z PATH...` | `7z d archive.7z MEMBER...` | `7z t archive.7z` | Built-in reader for supported 7z archives | LGPL-2.1-or-later (7-Zip); `p7zip-full` or `7zip`, `brew install sevenzip` |
| tar (`.tar`) | GNU `tar` / compatible `tar` | `tar -tvf archive.tar` | `tar -xf archive.tar -C DIR` | `tar -rf archive.tar PATH...` | `tar --delete -f archive.tar -- MEMBER...` | `tar -df archive.tar` compares with files on disk; no standalone checksum test | Built-in reader | GNU tar is GPL-3.0-or-later; `tar` (usually preinstalled), `brew install gnu-tar` |
| gzip stream / tar.gz / tgz | `gzip` + `tar` | `gzip -l file.gz`; for tar members use `gzip -dc archive.tar.gz | tar -tvf -` | `gzip -dc file.gz > DIR/FILE`; for tar use `tar -xzf archive.tar.gz -C DIR` | `gzip -c FILE > FILE.gz`; for tar use `tar -czf archive.tar.gz PATH...` | — | `gzip -t file.gz` | Built-in reader for `.gz` stem and nested tar.gz/tgz on Unix | GNU gzip is GPL-3.0-or-later; `gzip` (usually preinstalled), `brew install gzip` |
| bzip2 stream / tar.bz2 | `bzip2` + `tar` | `bzip2 -tv file.bz2`; for tar members use `bzip2 -dc archive.tar.bz2 | tar -tvf -` | `bzip2 -dc file.bz2 > DIR/FILE`; for tar use `tar -xjf archive.tar.bz2 -C DIR` | `bzip2 -c FILE > FILE.bz2`; for tar use `tar -cjf archive.tar.bz2 PATH...` | — | `bzip2 -t file.bz2` | Built-in reader for nested tar.bz2 on Unix | bzip2 license (BSD-like); `bzip2` (usually preinstalled), `brew install bzip2` |
| xz / txz / tar.xz | `xz` + `tar` | `xz -l file.xz`; for tar members use `xz -dc archive.tar.xz | tar -tvf -` | `xz -dc file.xz > DIR/FILE`; for tar use `tar -xJf archive.tar.xz -C DIR` | `xz -c FILE > FILE.xz`; for tar use `tar -cJf archive.tar.xz PATH...` | — | `xz -t file.xz` | Built-in reader for `.xz` and nested tar.xz/txz on Unix | Public-domain / GPL-2.0-or-later; `xz-utils`, `brew install xz` |
| zstd / tar.zst / tzst | `zstd` + `tar` | `zstd -l file.zst`; for tar members use `zstd -dc archive.tar.zst | tar -tvf -` | `zstd -dc file.zst > DIR/FILE`; for tar use `tar --use-compress-program=zstd -xf archive.tar.zst -C DIR` | `zstd -c FILE > FILE.zst`; for tar use `tar --use-compress-program=zstd -cf archive.tar.zst PATH...` | — | `zstd -t file.zst` | No external-wrapper reader yet | BSD-3-Clause or GPL-2.0-or-later; `zstd`, `brew install zstd` |
| RAR (`.rar`) | `unrar` (or `unar` for extraction) | `unrar l archive.rar` | `unrar x -o+ archive.rar DIR/` | `unrar a archive.rar PATH...` | `unrar d archive.rar MEMBER...` | `unrar t archive.rar` | Limited built-in support; RAR5 may need an external tool | `unrar` has a proprietary license; not bundled. `unar` is an alternative for reading/extraction. |
| CAB / WIM | `7z` | `7z l -slt -ba archive.cab` | `7z x -y -oDIR archive.cab` | `7z a archive.cab PATH...` | `7z d archive.cab MEMBER...` | `7z t archive.cab` | Partial built-in coverage; external fallback is a candidate | 7-Zip LGPL-2.1-or-later; `7zip` / `p7zip-full`, `brew install sevenzip` |
| Debian package (`.deb`) | `ar`, optionally `7z` | `ar t package.deb` (outer members); `7z l -slt -ba package.deb` | `ar x package.deb` in a fresh directory; `7z x -y -oDIR package.deb` | `ar r package.deb debian-binary control.tar data.tar` | Rebuild the package; do not mutate in place | `ar t package.deb` checks the container, not payload checksums | No general external-wrapper reader yet | GNU binutils `ar` is GPL-3.0-or-later; `binutils` (usually installed), `brew install binutils` |
| RPM (`.rpm`) | `7z` | `7z l -slt -ba package.rpm` | `7z x -y -oDIR package.rpm` | Use RPM build tooling, not a generic archive command | Rebuild the package | `rpm -K package.rpm` checks package signatures when RPM tooling is installed | No general external-wrapper reader yet | 7-Zip for reading (LGPL); RPM build tools have their own licenses; `rpm` package / `brew install rpm` |
| CPIO (`.cpio`) | `cpio` | `cpio -it < archive.cpio` | `cpio -idum < archive.cpio` in a fresh directory | `find PATH... -print0 | cpio --null -o > archive.cpio` | Rebuild the archive; no general portable in-place delete | `cpio -it < archive.cpio` checks that entries can be listed | No general external-wrapper reader yet | GNU cpio is GPL-3.0-or-later; `cpio`, `brew install cpio` |
| SquashFS (`.squashfs`) | `unsquashfs` | `unsquashfs -ll image.squashfs` | `unsquashfs -d DIR image.squashfs` | `mksquashfs SOURCE image.squashfs` | Rebuild the image | `unsquashfs -s image.squashfs` checks the superblock | No general external-wrapper reader yet | Squashfs-tools GPL-2.0-or-later; `squashfs-tools`, `brew install squashfs` where available |
| ISO 9660 (`.iso`) | `7z` (or `xorriso` for image authoring) | `7z l -slt -ba image.iso` | `7z x -y -oDIR image.iso` | `xorriso -as mkisofs -o image.iso SOURCE...` | Rebuild the image | `7z t image.iso` | No general external-wrapper reader yet | 7-Zip LGPL; xorriso GPL-3.0-or-later; `7zip xorriso`, `brew install sevenzip xorriso` |
| LHA/LZH (`.lha`, `.lzh`) | `lhasa` or `lha` | `lhasa l archive.lzh` | `lhasa x archive.lzh` | `lha a archive.lzh PATH...` | `lha d archive.lzh MEMBER...` | `lha t archive.lzh` | Built-in reader exists for some variants | Check the selected implementation's license; Debian `lhasa` / Homebrew `lhasa` |
| ZOO (`.zoo`) | `zoo` | `zoo l archive.zoo` | `zoo x archive.zoo` | `zoo a archive.zoo PATH...` | `zoo d archive.zoo MEMBER...` | `zoo -Test archive.zoo` (option spelling varies by implementation) | Built-in reader | Check the distribution implementation's license; often unavailable in current package managers |
| ACE (`.ace`) | `unace` | `unace l archive.ace` | `unace x archive.ace` | Not recommended; use a maintained format | — | `unace t archive.ace` | Built-in reader for supported versions | Proprietary / discontinued tool; do not bundle. Availability varies. |

For formats without a built-in reader, these rows are candidates for later steps, not a claim of current DN support. Before implementing a parser, capture the selected program's real output on fixtures and test its exact flags against the installed version. For compressed single-file streams, an archive browser can expose the decompressed stem as one virtual file; add/delete semantics do not apply to the compressed stream itself.
